It stays out of the way
until you press the shortcut.

The companion is a dock in the corner. It doesn't listen, it doesn't watch your screen, and nothing opens on its own.

  1. Press Ctrl+Shift+Space.

    A small panel opens beside whatever you're doing, no title bar, only as tall as what is in it. It grows as you talk and shrinks back to the dock when you close it.

  2. Press a question, or type one.

    The window you were in is a tile at the top, with its app's icon; three questions written for it sit under it. "Unstick me" for an error, "What does this output mean?" for a terminal, "Draft a reply" for mail. Press the tile to pick the whole desktop or any open window, and the questions follow. A screenshot, or for errors, spreadsheets and settings the window's exact text, shows in the box before it goes. There is no tick; the button reads "Send with screenshot" or "Send with window text", and just an arrow when only words go. Ctrl+Shift+E does the first one in one press and stops at Send.

  3. Hand it something bigger.

    Settings opens the studio beside the panel for a prototype. Computer mode is its own screen in the panel with a ten-minute permission and one approval per action. Both are explicit.

Computer mode:
one approved action at a time.

Runs in the Windows download only. This page can't inspect or control anything.

  1. Pick the app.

    Start a ten-minute control session. Open Notepad, Calculator or Paint, or pick a supported window that's already open. Sidelook reads its accessible controls locally.

  2. Say what to do.

    Choose a model and the effort. Allow a fresh reading of the window's accessible text, editable values included, to go to your model. No screenshot, no audio in this mode.

  3. Approve one action.

    Check the target, the replacement text or the shortcut. Approve runs exactly one operation, Reject runs nothing. Plan the next step to see what happened. Each step uses your allowance, and Anthropic models can spend paid credits.

  4. Stop whenever.

    Stop in Sidelook, untick the permission, or press Ctrl+Shift+F12 from any app. Approvals expire after a minute, sessions after ten, 20 model steps max. Stop doesn't undo what already ran.

Accessible controls only. No canvas drawing, no coordinate clicking, no Explorer, no terminal or address bar, no shell tool, no admin prompts. Not every app exposes usable controls. A click or a key in the target app can send, delete or buy something, so read each approval. Read the Computer mode guide

What leaves your machine,
and what doesn't.

What does this website collect?

The walkthrough runs in your browser. Vercel handles standard hosting request data and cookieless page-view analytics. This site never asks for your provider password or tokens.

What leaves my computer when I build?

The button says what goes, and What goes shows the request. Your prompt, any included frame, and the relevant previous source go through Codex to OpenAI or Claude Code to Anthropic, depending on the model you picked; with a local model in LM Studio or Ollama they stay on your computer. Camera sharing is explicit. Live build has its own consent for automatic snapshots, and the exact sent frame is there to review. No audio, no video stream. Credentials stay with the local CLI. Anthropic models can spend paid Claude credits.

Can I generate here without installing anything?

No. This website provides a prepared walkthrough. Real generation needs the local app and either a subscription with access to the model or a local model in LM Studio or Ollama. An account alone doesn't guarantee that access.

What if setup or generation fails?

Sign in, then use Check again in Settings. Sidelook shows missing access and usage limits plainly and never switches billing routes. Anthropic models show a live draft as HTML arrives, with scripts off until completion. OpenAI models release finished messages. Drop to low effort for smaller changes, and switch back to the last working version while you wait. Saved versions and source stay available when generation or preview fails.

Can I use voice, a camera, or an image instead?

Yes. Connect a camera, upload a JPEG, PNG or WebP, or build from typed directions alone. Windows local dictation turns your mic into editable text before you choose to build. Spoken replies use a local voice if you turn them on. Camera and dictation permissions are explicit, and desktop audio is never part of screen sharing.

What can I do with a finished prototype?

Use it in Desktop, Mobile or expanded preview. Read the Source, download the single HTML file, or restore one of up to 12 saved versions with its reference image. Settings, Advanced, Import a saved HTML prototype, brings in an exported file up to 120,000 bytes and adds a version when there's room. New project asks before clearing saved work. Browser profiles from a source install and older browser-based installs are separate. Runtime data inside a prototype resets when you reopen it. Retry preview reopens saved source without another model request.

Can it build a backend or control my desktop?

The builder makes frontend pages. Computer mode, enabled separately, drives accessible Windows controls with your approval before each action. No canvas drawing, no shell tool, no elevated access, no repo editing, no backend or deploy. Explorer, terminals, address bars and protected windows are excluded. The in-app preview blocks network access, nested frames, camera and microphone. Exported HTML runs outside that boundary.

Can I try anything before signing in?

The downloaded app has a working sample you can poke at without a model call or a login. Generating your own result needs subscription access or a local model. Settings offers install, sign-in, Check again and cancel. Start new allowance resets Sidelook's local counter only, not your provider's. Missing access and usage limits stop generation without switching models or billing.

Does this work on Mac or Linux?

The one-click launcher is Windows only. The source includes a Node.js server you can run elsewhere, but there's no Mac or Linux launcher in this download.
